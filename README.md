# Cross-Border Rides

Build a app Like BLA BLA in india for canada specially GTA area and vancover side. its gonna be ride sharing app where drivers will drop their route and pick up point and destination point and riders can pay in app and get connected

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://crossline-rides.lovable.app
